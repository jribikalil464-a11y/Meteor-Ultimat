# v0.4.0-dev

## Added
- Waypoint Manager: multiple named waypoints stored in the module's Meteor settings.
- Session Stats: local session timer and approximate travelled distance.
- Auto Sell preview-only mode: counts eligible stacks and stops without moving items.
- Auto Sell now leaves the GUI open if no eligible items were moved, and stops after preparing a batch when manual submission is selected.
- World Explorer scan interval setting and option to pause scanning while a screen is open.

## Still unverified
- Java compilation against the exact Meteor Client 1.21.4 artifact.
- Runtime behavior and rendering in Minecraft 1.21.4.
- Auto Sell menu slot behavior and server-specific sale confirmation.
